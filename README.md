## 📖 Sobre o Projeto / About the Project

**Quanto Custa Portugal** é uma plataforma completa desenvolvida para ajudar imigrantes e locais a entenderem o custo de vida real em Portugal. O projeto combina um **Blog** informativo com um **Dashboard Administrativo** robusto para gestão de cálculos fiscais, notícias e dados de mercado.

*Developed with ❤️ in Sesimbra, Portugal.*

---

## ✨ Funcionalidades / Features

### 🖥️ Dashboard (Internal Management)
- **Content Management:** Editor de artigos completo (CMS) para o blog.
- **Salary Calculator:** Simulador de salário líquido (IRS, Segurança Social).
- **Cost of Living Tracker:** Gestão de tabelas de preços e inflação.
- **User Management:** Controle de acesso e permissões.

### 📰 Blog (Public Interface)
- **Guides:** Informações sobre NIF, Bancos, Arrendamento e Saúde.
- **Dynamic News:** Notícias atualizadas sobre a economia portuguesa.
- **Interactive Tools:** Calculadoras integradas para o usuário final.

---

## 🛠️ Tecnologias / Tech Stack

- **Backend:** Python + Django (Modular Architecture)
- **Database:** PostgreSQL
- **Frontend:** TailwindCSS + JavaScript (Loyal to custom designs)
- **Environment:** macOS / Virtualenv
